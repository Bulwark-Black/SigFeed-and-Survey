📥 Ingest tool data — pull in scans, surveys, heatmaps

Accepts a survey .json, a Wi-Fi scan .csv (WiFi Explorer / NetSpot / inSSIDer), a monitor-mode packet capture .pcap / .pcapng, or a heatmap image. Scans & captures feed the report's interference analysis.
Export from each tool: WiFi Explorer → File → Export → CSV · NetSpot (paid) → Export → CSV/PNG · Apple Wireless Diagnostics → Scan → save · tcpdump monitor capture → sudo tcpdump -I -i en0 -w cap.pcap (or Wireshark .pcapng) · this app → "Save survey file" gives the .json.

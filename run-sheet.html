Field Run Sheet

Wi-Fi Site Survey

T-Mobile gateway + Waveform 2×2 antenna  ·  MacBook survey kit  ·  keep this handy on site
Start the tool: double-click start.command in the wifi-survey folder. Your browser opens the dashboard. Leave it on 😀 Easy mode.
Two jobs today: ① find the best spot to mount the antenna, then ② map the house for Wi-Fi dead spots. The app does the heatmap and the report. No other software needed.
New client? Top-right 🗂 survey button → ＋ New survey starts a fresh one; each client is saved separately and you can switch back anytime from that same menu.

✓ Before you start

  • MacBook charged; Wi-Fi on and joined to the client's gateway network
  • Gateway admin password in hand (it's on the sticker on the gateway)
  • Antenna not mounted yet: you'll find the best spot first
  • Know the rooms/areas the client says are slow

1 Find the best antenna spot (cellular)

The antenna isn't up yet, so you're hunting for the strongest spot to mount it. Higher SINR = better.

  1. Scroll to 📡 Cellular signal. Leave the address at 192.168.12.1, enter the admin password, tap Connect, tick "keep updating." A green ✅ Connected badge confirms it, and you'll see signal bars + all the numbers (SINR / RSRP / RSRQ / RSSI) for 5G and LTE.
  2. Carry the gateway to a candidate spot (near an exterior wall / window / upstairs, wherever the antenna could mount).
  3. Want the real internet speed at that spot? Tap ⚡ Test connection speed (~20 s). It shows the actual download/upload you're getting through the gateway.
  4. Wait ~15 seconds for the numbers to settle. Cellular lags.
  5. Type the spot name (e.g. "SE wall," "attic") and tap ＋ LOG.
  6. Repeat for each candidate spot. The app flags the best one ★ and puts the recommendation in the report.

2 Map the house (Wi-Fi dead spots)

Build the layout once, then walk and tap. The colored heatmap fills in as you go.

  1. Open 🗺️ Coverage from the left nav and pick what you're surveying.
  2. In the Coverage Map card, choose one:
    • ✏️ Draw a schematic: add rooms, drag to arrange, resize the corner, ✎ rename. For an odd-shaped room (L-shaped, angled) tap ◇ Shape room and tap each corner, then ✓ Finish shape. Enter the home's total sq ft if you know it.
    • 📐 Upload a photo/sketch of the floor plan instead.
    • 🛰 Aerial from address (outdoor / land surveys). Type the property address, tap Find, and a satellite image loads. Connect your phone on the 📍 GPS page, then walk the property: a blue "you are here" dot shows where you're standing on the aerial. Tap 📍 Mark my GPS spot to drop a reading at your location, and to map the lot line, tap ▱ Draw perimeter then stand on each corner and tap ＋ Corner at my GPS. Use −／＋ for a wider/closer view. Want it in Google Earth? Report page → 🌍 Export for Google Earth.
  3. Switch to 📍 Take readings. Walk to a room, stand in the middle, wait for the dial to settle.
  4. Tap the map where you're standing. That drops a colored dot AND logs the reading:
    E EXCELLENT   G GOOD   W WEAK   D DEAD ZONE
    Each dot on the map carries its letter as well as its colour.
  5. Cover every room plus the trouble spots below. Use 👁 Show/hide colors anytime to read labels.
Don't miss these:
  • Farthest bedroom from the gateway
  • Upstairs / basement
  • Garage & back porch / patio
  • Bathrooms (tile + mirrors block signal)
  • Kitchen (appliances / microwave)
  • Anywhere the client says "it's slow here"

3 Finish & deliver

  • On the 📄 Report page, fill in the client / owner name + property address at the top. They print on the report cover
  • Add any 📸 photos / screenshots (router spot, wiring, speed tests). Tap ＋ Add photos, give each a caption; they appear in the PDF
  • Tap 📄 MAKE THE REPORT → in the new tab, Print / Save as PDF
  • The PDF already includes it all: coverage heatmap, room-by-room table, antenna-placement pick, and findings
  • Tap ⬇︎ Save survey file to keep the raw data (re-open it later to reprint)
  • Hand the client: the PDF report + your final antenna-spot numbers
Handy: Switch to ⚙️ Advanced anytime for exact numbers, a nearby-network / channel check, and a per-room throughput (speed) test. The 🩺 Wireless Diag button opens Apple's built-in scanner for a second opinion.
